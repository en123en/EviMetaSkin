# Reported artifacts

This directory contains compact tables, metrics, and final figures preserved from the experiments reported in the manuscript. Paths embedded in some CSV or Markdown files refer to the original research workspace and are retained as provenance.

Raw datasets, full experiment trees, and model checkpoints are intentionally excluded because of dataset licenses and file size. New runs are written to `results/experiments`, `results/analysis`, `results/tables`, and `results/figures`; these directories are ignored by Git.
